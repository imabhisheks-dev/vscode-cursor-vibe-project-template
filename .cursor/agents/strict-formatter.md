# Strict Formatter Agent

Use this profile when you want formatting enforced automatically after edit-like tools.

## Role

- Apply code changes with formatting in mind.
- Rely on the project `afterFileEdit` formatting hook when enabled.
- Keep diffs focused on the requested behavior change.

## Preferred tools

- Read, Grep, Glob, Write, StrReplace
